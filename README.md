# CSV 概览工具

仅使用 Python 3 标准库，无需安装依赖。在项目目录运行：

```sh
python3 csv_overview.py examples/sample.csv
```

输出：

```text
列名：姓名、城市、备注
数据行数：3
每列空值数量：
  姓名：0
  城市：1
  备注：2
每列非空值数量：
  姓名：3
  城市：2
  备注：1
```

也可以传入自己的文件路径（包含空格时请加引号）：

```sh
python3 csv_overview.py "/路径/我的数据.csv"
```

## 统计规则

每列非空值数量 = 数据行数 − 该列空值数量；每列两项数量之和始终等于数据行数。数字 `0` 和文本 `NULL` 等非空白内容均计为非空值。

- 输入使用 UTF-8，兼容 UTF-8 BOM 和中文路径、中文内容。
- 第一条非空记录作为列名，不计入数据行数；按逗号分隔，支持引号内逗号和换行。
- 空字符串、仅含空白的字段和行末缺失字段计为空值。完全空白的行忽略；`,,` 这样的记录仍计数。
- 空文件输出无列、零行；只有表头时，各列空值为零。
- 字段超过表头列数时报告错误，避免静默丢失数据。重复列名仍按位置分别统计。
- 路径不存在、无法读取、编码错误或 CSV 格式错误时，向标准错误输出提示并以状态码 1 退出；成功为 0。
- 逐行读取，内存使用随列数增长，无需将全部数据载入内存。

## 测试

```sh
python3 -m unittest -v
```

覆盖开头空行、纯空行文件、错误编码和格式的命令行退出状态、中文与 BOM、空值、缺失字段、空文件、仅表头、引号与跨行字段、过多字段、路径不存在和示例命令输出。
